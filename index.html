Introduction

  • HTML (HyperText Markup Language) is the standard markup language used to create web pages. It provides the basic structure of a webpage by organizing content such as text, images, links, tables, forms, audio, and videos. Every website on the internet is built using HTML along with CSS and JavaScript. HTML uses tags to define different elements, allowing web browsers to display content correctly.

  • To use HTML, you will need:
    1.A text editor (e.g., VS Code, Atom)
    2.A web browser

Structure of HTML

  • The main elements of HTML are:
    • <!DOCTYPE html>:

      • Declares the document type and version of HTML.

    • <html>:

      • The root element of an HTML page.

    • <head>:

      • Contains meta-information about the document.

    • <body>:

      • Contains the content that will be displayed on the web page.

Lists

HTML (HyperText Markup Language) provides different ways to organize and display information on a web page. One of the most useful features of HTML is the list element. Lists help present information in a structured and organized manner, making web pages easier to read and understand. Instead of writing long paragraphs, developers can use lists to display items, steps, instructions, menus, or categories clearly. HTML supports three main types of lists: Ordered Lists, Unordered Lists, and Description Lists. Each type serves a different purpose depending on how the information needs to be presented.

Lists are commonly used in websites for navigation menus, product features, recipes, instructions, educational content, FAQs, and many other applications. They improve readability, enhance user experience, and make webpage content well organized.

Types of Lists in HTML

HTML provides the following three types of lists:

  1. Ordered List
  2. Unordered List
  3. Description List
    4. Each list type uses specific HTML tags to display information.

Tables in HTML

HTML tables are used to display data in a structured format using rows and columns. They help organize information such as student records, employee details, product lists, timetables, and reports in an easy-to-read manner.

An HTML table is created using the <table> tag. Each table contains rows created with the <tr> tag and cells created with the <td> tag. Table headings are created using the <th> tag, which displays important column names.

Table Elements in HTML

  • <table>: Defines the beginning and structure of an HTML table.
  • <tr>: Defines a row inside the table.
  • <th>: Defines table headings and usually appears as bold text.
  • <td>: Defines individual data cells inside a table.
  • <caption>: Adds a title or description for the table.

Features of HTML Tables

  • Displays data in rows and columns.
  • Makes complex information easier to understand.
  • Supports merging rows and columns using rowspan and colspan.
  • Can be used to create structured layouts.
  • Helps present large amounts of data clearly.

Table Attributes

  • border: Adds a border around the table and its cells.
  • cellpadding: Adds space between the cell content and the cell border.
  • cellspacing: Adds space between table cells.
  • rowspan: Combines two or more rows into one cell.
  • colspan: Combines two or more columns into one cell.

Multimedia in HTML

HTML allows us to add multimedia content such as images, audio, and videos to web pages. Multimedia makes websites more attractive, interactive, and informative. HTML provides special tags to display different types of media content directly in a browser.

The main multimedia elements in HTML are:

  • Images: The <img> tag is used to add images to a webpage. Images can improve the visual appearance and provide additional information.
  • Audio: The <audio> tag is used to add sound or music to a webpage. It supports different audio formats.
  • Video: The <video> tag is used to embed videos into a webpage. It allows users to play videos directly in the browser.

Hyperlinks in HTML

Hyperlinks are used to connect one webpage to another webpage or to different sections of the same webpage. They allow users to navigate easily between pages and websites.

HTML creates hyperlinks using the anchor tag <a>. A hyperlink can link to another website, a file, an email address, or a specific location on a page.

Common uses of hyperlinks:

  • Connecting different web pages.
  • Creating navigation menus.
  • Linking documents and files.
  • Opening external websites.

Forms in HTML

  • <form>: Defines the beginning and structure of an HTML form.
  • <input>: Creates input fields where users can enter information. It supports different types such as text, password, email, radio buttons, checkboxes, and submit buttons.
  • <label>: Provides a description or name for an input field. It helps users understand what information should be entered.
  • <textarea>: Creates a multi-line text box where users can enter longer messages or comments.
  • <select>: Creates a drop-down list that allows users to select an option from multiple choices.
  • <option>: Defines the options inside a drop-down list.
  • <button>: Creates a clickable button to submit or perform an action.

Types of Input Fields

  • Text: Used to enter single-line text information.
  • Password: Used to enter secure information that is hidden from view.
  • Email: Used to enter an email address.
  • Radio Button: Allows users to select one option from a group of choices.
  • Checkbox: Allows users to select multiple options.
  • Submit: Creates a button to send form data.

Semantic Elements and HTML Layout

HTML semantic elements are elements that clearly describe the meaning and purpose of the content inside them. They make the structure of a webpage easier to understand for developers, browsers, and search engines.

Before semantic elements were introduced, developers mainly used the <div> tag to create webpage sections. Semantic elements provide meaningful names to different parts of a webpage, making the code more organized and readable.

Common Semantic Elements in HTML

  • <header>: Defines the top section of a webpage. It usually contains the website logo, title, and introductory content.
  • <nav>: Represents a navigation section that contains links to different pages or sections of a website.
  • <section>: Defines a separate section of content in a webpage. It is used to group related information.
  • <article>: Represents independent content such as blog posts, news articles, or tutorials.
  • <aside>: Defines additional content related to the main content, such as sidebars or related links.
  • <footer>: Defines the bottom section of a webpage. It usually contains copyright information, contact details, or additional links.
  • <main>: Represents the main content area of a webpage.

HTML Layout

HTML layout refers to the way content is arranged and displayed on a webpage. A good layout helps organize information and improves the user experience.

A typical webpage layout contains different sections such as a header, navigation menu, main content area, sidebar, and footer.

Basic Structure of HTML Layout

Element Purpose
<header> Contains the webpage title, logo, or introduction.
<nav> Contains navigation links.
<main> Contains the main information of the webpage.
<aside> Contains additional information or side content.
<footer> Contains copyright and contact information.

Advantages of Semantic Elements

  • Makes HTML code easier to read and maintain.
  • Improves website structure and organization.
  • Helps search engines understand webpage content.
  • Improves accessibility for users with assistive technologies.
  • Makes website development easier.

Importance of HTML Layout

A well-designed HTML layout helps present information clearly and creates a better browsing experience. Semantic elements and proper layout structure are important for building modern, organized, and user-friendly websites.
