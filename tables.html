HTML Tables

What is an HTML Table?

An HTML table is used to display data in a structured format using rows and columns. Tables are useful for presenting information such as student records, employee details, product lists, timetables, and reports.

HTML Table Tags

Tag Description
<table> Defines the table.
<tr> Defines a table row.
<th> Defines a table heading.
<td> Defines table data (cell).
<caption> Adds a title to the table.

Common Table Attributes

Attribute Purpose
border Adds a border around the table.
cellpadding Adds space inside each cell.
cellspacing Adds space between table cells.
rowspan Merges multiple rows into one cell.
colspan Merges multiple columns into one cell.

Advantages of HTML Tables

  • Displays data in rows and columns.
  • Easy to read and understand.
  • Organizes large amounts of information.
  • Supports rowspan and colspan.
  • Can be styled using CSS.

Applications of HTML Tables

  1. Student Marks Tables
  2. Employee Records
  3. Product Catalogs
  4. School Timetables
  5. Hospital Reports
  6. Bank Statements
  7. Sales Reports
  8. Inventory Management

Conclusion

HTML tables are an important part of web development. They are used to organize and display structured data effectively. By using tags such as <table>, <tr>, <th>, and <td>, developers can create well-organized tables. Features like rowspan and colspan make tables more flexible and easier to understand.
