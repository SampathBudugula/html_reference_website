HTML Hyperlinks

What is a Hyperlink?

A hyperlink is a clickable text or image that allows users to navigate from one web page to another or to a specific location within the same page. Hyperlinks are created using the <a> (Anchor) tag in HTML. They are one of the most important features of the World Wide Web because they connect web pages and resources together.

Syntax of Hyperlink

<a href="URL">Link Text</a>

The href attribute specifies the destination of the link.

HTML Hyperlink Tags and Attributes

Tag / Attribute Description
<a> Defines a hyperlink.
href Specifies the destination URL.
target Specifies where the linked document opens.
title Displays additional information when the mouse is placed over the link.
download Downloads the linked file instead of opening it.

Examples of Hyperlinks

1. External Link

<a href="https://www.google.com">Visit Google</a>

Visit Google

2. Internal Link

<a href="about.html">About Us</a>

About Us

3. Email Link

<a href="mailto:example@gmail.com">Send Email</a>

Send Email

4. Telephone Link

<a href="tel:+919876543210">Call Us</a>

Call Us

Target Attribute Values

Value Description
_self Opens the link in the same browser tab (default).
_blank Opens the link in a new browser tab.
_parent Opens the link in the parent frame.
_top Opens the link in the full browser window.

Advantages of Hyperlinks

  • Connects web pages easily.
  • Improves website navigation.
  • Provides quick access to resources.
  • Enhances user experience.
  • Supports linking to files, emails, and phone numbers.
  • Helps organize website content.

Applications of Hyperlinks

  1. Website Navigation Menus
  2. Online Documentation
  3. Educational Websites
  4. E-commerce Websites
  5. Social Media Platforms
  6. News Websites
  7. Blog Articles
  8. Download Pages

Conclusion

Hyperlinks are one of the most essential features of HTML. They allow users to move from one web page to another, access online resources, send emails, make phone calls, and download files. The <a> tag, along with attributes like href, target, and download, provides a simple and powerful way to create navigation in websites. Proper use of hyperlinks improves both the usability and accessibility of web pages.
